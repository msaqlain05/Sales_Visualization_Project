# Python Data Visualization Project Using Matplotlib

**Name:** Muhammad Saqlain
**Registration No:** 2024-KIU-BS5408

Monthly sales analysis of 4 products (Laptops, Smartphones, Headphones, Smartwatches) over 6 months.

## How to run

### Linux / macOS
```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python sales_analysis.py
```

### Windows
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python sales_analysis.py
```

## Folder structure
```
Sales_Visualization_Project/
|-- sales_analysis.py      (complete source code)
|-- requirements.txt       (matplotlib)
|-- data/sales_data.csv    (my dataset)
|-- charts/                (5 PNG images)
`-- report/Sales_Analysis_Report.pdf
```
